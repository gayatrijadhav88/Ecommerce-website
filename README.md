# Ecommerce-website
E-Commerce Website Project
SmartCommerce AI – Short Project Description

SmartCommerce AI is an AI-powered e-commerce platform built using the MERN Stack and Python AI services. It enables users to browse products, manage carts and orders, and receive personalized product recommendations. The platform also includes semantic search and an AI shopping assistant to enhance product discovery and customer experience. Administrators can manage products, users, orders, and view business analytics through a modern dashboard.

Technologies: React.js, Node.js, Express.js, MongoDB, FastAPI, Scikit-Learn, FAISS, LangChain, Gemini API, Tailwind CSS.
