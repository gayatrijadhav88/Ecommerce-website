# Viva Questions and Answers

**Q1. What is SmartCommerce AI?**  
It is a MERN e-commerce platform enhanced with AI recommendations, semantic search, and an AI shopping assistant.

**Q2. Why use JWT?**  
JWT provides stateless authentication and allows protected APIs to verify user identity and role.

**Q3. What is RBAC?**  
Role-Based Access Control restricts actions based on user roles, such as customer and admin.

**Q4. How does content-based recommendation work?**  
It converts product text into vectors and compares user browsing history with products using cosine similarity.

**Q5. Why use FAISS?**  
FAISS performs efficient similarity search over embedding vectors.

**Q6. What is RAG?**  
Retrieval-Augmented Generation gives the language model relevant product context before generating an answer.

**Q7. Why separate AI services from backend?**  
It keeps Node.js APIs focused on commerce and lets Python handle ML libraries cleanly.

**Q8. What database is used?**  
MongoDB Atlas with Mongoose schemas.

**Q9. How is browsing history tracked?**  
When a logged-in user views a product, the backend stores a BrowsingHistory document.

**Q10. How can the project be improved?**  
Add payment gateway, reviews, inventory alerts, coupon engine, automated tests, and image upload storage.
