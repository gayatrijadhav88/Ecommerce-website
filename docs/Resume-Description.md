# Resume Project Description

Built SmartCommerce AI, a production-structured MERN e-commerce platform with JWT authentication, role-based admin controls, product/catalog management, cart, wishlist, checkout, orders, profile management, and analytics dashboards. Integrated Python FastAPI AI microservices for content-based recommendations using cosine similarity, semantic product search using Sentence Transformers and FAISS, and a LangChain/Gemini-powered RAG shopping assistant. Designed responsive Tailwind CSS UI, MongoDB/Mongoose schemas, deployment-ready configuration for Vercel/Render/MongoDB Atlas, and complete final-year-project documentation.
